AIM:

ㅤ
	To sketch the given drawing with dimensions using fusion 360 tool.
	
REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16GB of RAM (integrated graphics recommend 2 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload
   
PROCEDURE:

1. Open a new file and then select the sketch icon.
2. Select the plane of sketching.
3. Use Sketching features (line, circle, arc, rectangle, polygon, etc.,) to draw to given sketch
   
<img width="331" height="532" alt="Screenshot 2026-10-05 105221" src="https://github.com/user-attachments/assets/3c4fecbd-c705-4f42-8825-31e53663c8b8" />

4.Use sketch modifying features (trim, mirror, move, etc.,) to edit the sketch

<img width="223" height="338" alt="Screenshot 2026-10-05 105834" src="https://github.com/user-attachments/assets/b5b8d83c-275a-4fee-a7c8-64fcc1a945ea" />

5.Use the Constraints feature and apply the Tangent tool to join the circles smoothly and create the required curves.

<img width="285" height="452" alt="Screenshot 2026-10-05 110525" src="https://github.com/user-attachments/assets/8844fc19-19d4-47ee-9e8a-7e772a540cba" />

6. Draw the main rectangular base using the Line tool with a length of 100 mm, a width of 50 mm, and a height of 50 mm
7. Draw a circle of diameter 50 mm on the front face using the Circle tool 
8. Use the Extrude tool to extend the circular feature outward by 20 mm 
9. Draw the inclined section on the top surface using the Line tool and set the angle to 45° 
10. Create the raised rectangular block on the top surface using the Rectangle tool 
11. Use the Extrude tool to give the raised block the required height 
12. Draw a small square on the upper-left surface using the Rectangle tool 
13. Use the Extrude tool to raise the square into a small rectangular projection 
14. Draw a circle of diameter 20 mm on the upper-right surface using the Circle tool 
15. Use the Extrude tool to create the circular projection on the top surface 
16. Use the Line tool to complete the remaining inclined edges and boundaries 
17. Apply the necessary dimensions and constraints to maintain the correct size and alignment of all features 
18.	Line – Used to draw the straight edges of the diagram.
	Circle – Used to create the circular holes/features in the diagram.
